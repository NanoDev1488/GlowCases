# GlowCases ✨ (HolyWorld Style Cases)

**GlowCases** — это высокопроизводительный, легковесный и полностью настраиваемый плагин на кейсы в стиле сервера **HolyWorld** для Minecraft Paper/Spigot (1.16.5 – 1.21.x).

---

## 🌟 Основные возможности

- 🎰 **Плавная CS:GO / Рулетка анимация**:
  - Анимация замедления вращения (экспоненциальная кривая).
  - Звуковое сопровождение каждого тика и победного звука (`UI_TOAST_CHALLENGE_COMPLETE`).
  - Верхний и нижний указатели выигрышного слота.
  - Защита от дюпа, кликов и закрытия инвентаря во время прокрутки.
- 🔮 **3D Голограммы и парящие вращающиеся предметы**:
  - Встроенная система голограмм над блоками кейсов без обязательной зависимости от сторонних плагинов.
  - Парящий вращающийся блок/предмет кейса.
  - Интерактивность: **ЛКМ** — просмотр содержимого и шансов, **ПКМ** — открытие кейса.
- 📜 **Меню предпросмотра (Preview GUI)**:
  - Просмотр всех предметов, их редкостей и точных процентов шанса выпадения.
- 🗄 **Мульти-хранилище (Multi-Storage Backend)**:
  - Поддержка **SQLite** (быстрая локальная база данных без настройки).
  - Поддержка **MySQL / MariaDB** через высокоскоростной пул соединений **HikariCP**.
  - Поддержка **YAML** (плоские файлы в папке `userdata/`).
  - Асинхронная загрузка и сохранение без микрофризов сервера.
- 💎 **Поддержка RGB и градиентов**:
  - Полная поддержка современных HEX цветов (`&#rrggbb` и `&x&r&r&g&g&b&b`).
- 📢 **Глобальные оповещения и эффекты**:
  - Оповещения в чат о редких выигрышах с отображением шанса и редкости.
  - Запуск фейерверков и показ Title/Subtitle на экране.
- 🧩 **Интеграции**:
  - **PlaceholderAPI** (`%glowcases_keys_<кейс>%`, `%glowcases_opened%`, `%glowcases_opened_<кейс>%`).
  - **Vault** (выдача валюты, экономические кейсы).
  - **LuckPerms** (выдача доната в Донат-Кейсе).

## 📋 Команды и права

| Команда | Описание | Право |
|---|---|---|
| `/cases` (алиасы: `/case`, `/donatecases`) | Открыть главное меню кейсов | `glowcases.use` (по умолчанию у всех) |
| `/glowcases help` | Показать список всех команд | `glowcases.admin` |
| `/glowcases givekey <игрок> <кейс> <кол-во>` | Выдать ключи игроку | `glowcases.admin` |
| `/glowcases setkey <игрок> <кейс> <кол-во>` | Установить количество ключей | `glowcases.admin` |
| `/glowcases takekey <игрок> <кейс> <кол-во>` | Забрать ключи у игрока | `glowcases.admin` |
| `/glowcases keys [игрок]` | Просмотреть ключи игрока | `glowcases.admin` |
| `/glowcases setcase <кейс>` | Привязать блок, на который вы смотрите, к кейсу и создать голограмму | `glowcases.admin` |
| `/glowcases delcase` | Удалить привязку блока и голограмму | `glowcases.admin` |
| `/glowcases reload` | Перезагрузить конфигурации, кейсы и голограммы | `glowcases.admin` |

## 🎁 Готовые предустановленные кейсы

В папке `cases/` уже настроены популярные кейсы с точным оформлением HolyWorld:
1. `donate.yml` — **Донат Кейс** (VIP, Premium, Creative, Lord, Titan, Dragon, Sponsor).
2. `runes.yml` — **Кейс с Рунами** (Руна Скорости, Руна Силы, Руна Регенерации, Руна Бессмертия).
3. `spawners.yml` — **Кейс со Спавнерами** (Зомби, Скелеты, Ифриты, Железные Големы).
4. `titles.yml` — **Кейс с Титулами** ([Новичок], [Воин], [Анархист], [Легенда]).
5. `money.yml` — **Кейс с Валютой** ($10k, $50k, $200k, $1,000,000).

## 🛠 Сборка плагина

Для сборки `.jar` файла выполните в папке проекта:
```bash
mvn clean package
```
Готовый плагин будет создан в папке `target/GlowCases-1.0.0.jar`.
